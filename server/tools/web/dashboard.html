What you are talking to

This panel runs Claude (Claude Code, headless) with exactly one set of tools: our elrobot MCP server (tools/elrobot_mcp.py). The Model Context Protocol is the open standard AI apps use to plug in tools; the server speaks it over stdin/stdout, so Claude Code, Claude Desktop or OpenAI Codex can all drive the arm.

How a request flows

You: "pick the orange ball"
▼
Claude decides which tools to call
▼ MCP (JSON-RPC over stdio)
elrobot MCP server: 15 tools
▼
arm_control: inverse kinematics, safety checks, vision (OpenCV)
▼
NormaCore Station → 8 servos + 2 cameras
▲ every motion tool returns BOTH camera images
Claude looks, checks, and decides the next step

Safety, built into the tools

Max 15 cm per move · no move that would hit the desk · stops when a joint is blocked · gentle gripper squeeze · the arm only goes where inverse kinematics says it can. In this panel Claude has no shell, file or web tools: only the robot.
